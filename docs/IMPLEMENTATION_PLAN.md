This plan is the active work queue for [the tailored completion brief](SUMAMS_CODEBASE_COMPLETION_PROMPT.md). “Completed” means verified to its acceptance criteria, not merely that code exists.

## Current milestone

**M1 — Scope alignment and P0 remediation.** The tailored prompt, architecture map, audit, feature matrix, and plan are present. Razorpay actions enforce signed-in ownership; provider-order creation is linked conditionally; payment and order references remain separate. Migration 026 protects exact-variant settlement; migration 027 guards status changes; migration 029 adds durable manual payment review with locked/rechecked coupon capacity and an attributable staff resolver; migration 030 enables trusted admin bootstrap; migration 031 makes category reordering atomic; migration 032 isolates the public CMS payload from draft columns. Product/avatar uploads check file signatures. Checkout maps known database errors to safe customer text, email logs omit provider response bodies, and admin dashboard data outages are displayed as unavailable. Latest tests (16 files/114 tests), lint, and typecheck pass; the latest Webpack build failed with Windows `EPERM` creating a route directory under `.next`. SQL/provider runtime is unverified. The user confirmed Supabase is production and forbade breaking it, so no migration will be applied there.
